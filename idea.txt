Hola, quiero que me ayudes a crear una poryecto HTML + CSS + JS + GITHUB, para luego cargar el proyecto a Github y que los usuarios la descarguen, es decir, que vayan a Chrome, toquen los tres puntitos y toquen guardar como aplicacion.
Que la aplicacion se llame: "TusTareas" y que pueda cumplir estas funciones:
1- Un sistema de login con usuarios pre-cargados.
2- Un sistema de auto-login.
3- Un sistema de notificaciones diarios.
4- Un sistema de pestañas para podes pasar de una a otra con animaciones en los botones y etc.
5- Que sea linda esteticamente.
6- Que no use emojis.

1- El sistema de login funcionara asi.
    1. En la pestaña que carga al iniciar la app "login", habra un campo que sera para poner el nombre del usuario y un boton.
    2. Cuando el usuario haya dado click en el boton, el sistema tendra que verificar si el usuario introducio algo en el campo...
        2.1. Si el usuario no puso nada, marcara error y le pedira que ponga algo.
        2.2. Si el usuario puso algo, se buscara en la tabla de usuarios, algun usuario con ese usuario, recorda que se ignoraran faltas de tildes y/o faltas de mayusculas o minusculas.
    3. Si no se encuentra un usuario con ese nombre en la tabla, se marcara error.
    4. Si se encuentra un usuario con ese nombre en la tabla, se guardara localmente que en el dispositivo donde de esta ejecutando la app, ese es de el usuario en el que se logueo, luego de guardar los datos el usuario sera llevado a la pestaña: "inicio".

2- El sistmea de auto-login funcionara asi:
    1. Al cargar la app, se buscara que localmente se hayan guardado datos de inicio de sesion.
        1.1. Si no se encunetran se cancelara la funcion y se dejara que el usuario se loguee.
        1.2. Si se encuentran datos, se cargara la pestaña: "inicio".

3- El sistema de notificaciones diarios funcionara asi:
    De Lunes a Viernes se mandaran notificaciones a las 8pm (si no se puedo mandar a esa hora, se intentara mandar nuevamente cada 2 minutos).
    Las notificaciones tendran este formato: "Buenos dias [usuario], hoy te tocan estas tareas: [tareas del dia de hoy]". (Si en alguna de las 8am tareas no tiene nada y/o una X significa que no le toca esa tarea ese dia). (Que las tareas esten separadas por una coma ej: "[tarea #], [tarea #]...)
